PowerPoint add-in for Windows

The last forbidden feature in PowerPoint.

Frame-by-frame animation, on the slides you already have.

What lands on the ribbon.

01 — Guide

Create Guide

Ghosts the previous slide onto this one.

02 — Guide

Clear Guide

Takes it off this slide. Clear All Guides is in the menu.

03 — Export

Export

PNG or SVG per slide, a GIF, or an MP4 at 1080p. Guides stay out.

Classic or Duplicate.

Pick what a new slide does under Animation Mode. Off leaves PowerPoint alone.

Classic

New slide is blank, with a guide. Redraw the frame.

vs

Duplicate

New slide is a copy, with a guide underneath. Nudge what moved.

Install it once.

  1. Download OnionPPT.ppam.
  2. File → Options → Add-ins. Next to Manage, pick PowerPoint Add-ins and click Go…
  3. Click Add…, pick the file, and leave it checked.

Windows PowerPoint, with macros allowed for the add-in. Building from source is in the install notes.
